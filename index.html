Privacy

FAQ

Frequently asked questions.

Does Kingly require an account?

No. Kingly has no sign-in, no account creation and no email verification. Install, open, start typing.

Where is my data stored?

All data lives in a sandboxed JSON file inside the Kingly app container on your iPhone. It is protected by iOS app sandbox isolation and is never transmitted anywhere.

Can I export my data?

Yes. Settings → Data → Export creates a single JSON file containing every account, transaction, holding, budget and theme preference. You can share it via Files, AirDrop, email or any other iOS share target.

Does Kingly support multiple currencies?

Yes. Kingly supports USD, EUR, GBP, JPY, CNY, HKD, SGD, AUD, CAD and CHF as a base currency, configurable in Settings → Preferences → Currency.

What happens if I delete the app?

All data is permanently erased. There is no cloud backup and no recovery. We recommend exporting a JSON snapshot first if you want to migrate or restore later.

Does Kingly support iPad?

Kingly is currently iPhone-only, optimised for iOS 16 and later. An iPad-native layout is on the roadmap.

Is Kingly free?

Kingly is a one-time paid download with no subscriptions, no ads and no in-app purchases.
